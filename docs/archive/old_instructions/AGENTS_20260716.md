# AGENTS.md

最后更新：`2026-07-16`

## 项目定位

项目名称：`DatasetDistillationforSocialLearning`。

当前研究方向：面向架构异构社会化学习的高知识密度蒸馏通信包构建。

暂定题目：

```text
Distilled Knowledge Packets for Communication-Efficient Heterogeneous Socialized Learning
```

中文题目：

```text
面向异构社会化学习的高知识密度蒸馏通信包构建方法
```

本文研究 class-disjoint agents 如何在通信受限、模型架构异构的条件下，保持自身 expert knowledge，同时吸收其他 agent 的 non-expert knowledge。agent 之间传输的是输入空间 image packet 及其可选 soft labels，不传模型参数、梯度或中间特征。

这不是联邦学习中的模型聚合问题。当前任务没有中心服务器聚合、全局模型同步或同构参数平均；核心是 agent-to-agent 的社会化知识传递。

## 当前唯一有效的实验设定

本节是截至 `2026-07-15` 的当前口径。旧的 VGG、ResNetAP、hetero6arch、全 ConvNet family 和标准化共享架构 packet encoder 设定均不再作为当前主实验描述。

### 数据与 agent

```text
数据集：CIFAR-100
agent 数量：4
类别划分：每个 agent 拥有互不重叠的 25 个 expert classes
模型输出维度：固定为 100
```

```python
agent_class_split = {
    0: list(range(0, 25)),
    1: list(range(25, 50)),
    2: list(range(50, 75)),
    3: list(range(75, 100)),
}
```

所有标签保留 CIFAR-100 全局标签 `0-99`，禁止重映射为局部 `0-24`。即使 agent 只训练 25 个 expert classes，分类头仍然必须输出 100 维。

### 架构异构模型池

当前只使用以下四类模型：

```text
ConvNet-3-w1.0
ConvNet-4-w1.5
AlexNet-CIFAR
ResNet-CIFAR compact（ResNet-10-CIFAR-w0.5 或 ResNet-18-CIFAR-w0.5）
```

每个 seed 的 4 个 agent 恰好包含一个 ConvNet-3、一个 ConvNet-4、一个 AlexNet 和一个 ResNet。当前三组固定 split：

```text
seed0:
  agent_0 = AlexNet      classes 0-24
  agent_1 = ConvNet-3    classes 25-49
  agent_2 = ResNet-18    classes 50-74
  agent_3 = ConvNet-4    classes 75-99

seed1:
  agent_0 = ConvNet-4    classes 0-24
  agent_1 = AlexNet      classes 25-49
  agent_2 = ResNet-10    classes 50-74
  agent_3 = ConvNet-3    classes 75-99

seed2:
  agent_0 = AlexNet      classes 0-24
  agent_1 = ResNet-18    classes 25-49
  agent_2 = ConvNet-3    classes 50-74
  agent_3 = ConvNet-4    classes 75-99
```

历史配置 ID `resnet10` / `resnet18` 保持不变以兼容已有 checkpoint，但其实际实现是
CIFAR 3x3 stem、base width 32 的 compact ResNet：

```text
ResNet-10-CIFAR-w0.5 = 1,252,100 参数
ResNet-18-CIFAR-w0.5 = 2,820,740 参数
```

不能再把当前主实验的 `resnet18` 写成约 11M 参数的 canonical ResNet-18。新增的
`family: resnet_cifar_standard` 使用 base width 64，ResNet-18 为 11,220,132 参数，
仅用于隔离诊断；它不替换、不混入已完成的 one-ResNet 主结果。

论文中的 heterogeneity 特指 architectural heterogeneity：模型家族、深度、宽度、归一化方式、参数形状和特征维度不同。硬件能力差异是现实动机，但当前实验不验证异步、掉线、动态带宽或真实硬件延迟。

## 当前方法：异构 agent 自蒸馏 packet

当前主方法是 per-agent、backbone-aligned self-distillation：

```text
Agent local expert data
→ locally trained guide pool with the agent's own backbone architecture
→ DSDM condensation
→ sender-specific distilled image packet
→ other heterogeneous receivers
```

具体含义：

```text
ConvNet-3 sender  → local ConvNet-3 guides  → DSDM packet
ConvNet-4 sender  → local ConvNet-4 guides  → DSDM packet
AlexNet sender    → local AlexNet guides    → DSDM packet
ResNet sender     → local ResNet guides     → DSDM packet
```

这里的“自蒸馏”表示 packet synthesis 与 sender 自身的 backbone architecture 对齐，guide 只使用该 sender 的 25 类本地数据训练。不同 agent 不共享 guide 权重，不存在全局 teacher，也不使用统一 ConvNet 替所有 agent 生成 packet。

不要再把当前方法表述为：

```text
共享 ConvNet teacher
标准化 ConvNet packet encoder 是当前主方法
所有 agent 复用同一个 encoder 权重
hetero6arch/VGG 是当前模型池
```

当前方法的核心价值是：sender-specific 蒸馏图仍处于输入空间，因此不同架构的 receiver 都能直接消费；同时，DSDM 提升有限图像通信预算下的知识密度。

### Logits 口径

Logits 是 image packet 的增强注释，不是主要通信载体，也不是第一层研究动机。

```text
只保存 sender expert classes 上的 logits
不保存完整 100-class logits
不保存参数、梯度、中间特征或激活
```

当前主结果使用 `DSDM + Logits`。按当前 baseline 口径，Random/Heuristic 与 FAST
都只传输真实图和 hard label，不附加 logits。因此主表比较的是完整方法，不应把
Ours 相对真实图 baseline 的全部增益都归因于 synthetic image；logits 的独立贡献
应由 `DSDM` 与 `DSDM + Logits` 消融给出。

## 当前对比方法

当前主要对比方法：

```text
1. Random：每个 expert class 随机选取 IPC 张真实图；代码名 heuristic；hard label、无 logits。
2. FAST：CVPR 2026 DNN-free 核心集选择；每类选取 IPC 张真实图，hard label、无 logits。
3. MASC：社会化学习代表方法，使用官方实现并适配固定 class split。
4. DeSA：synthetic-anchor / data-free social learning 对比，使用官方或已记录的 comparable adaptation。
```

主表中应明确区分各方法实际传输对象和适配条件。MASC 与 DeSA 的原始任务、训练流程和通信对象不完全等同于本文，不能把适配结果表述为完全无条件的原论文复现。

以下项目只作为诊断或上界，不属于当前三个主要对比方法：

```text
Expert Only：社会化前性能
Full Real：传输全部真实数据的 oracle / upper bound
Centralized Full Data：模型能力诊断，不属于 social learning
```

`importance`、FedProto、FedRE 可以保留已有代码和历史产物，但不再写入当前主实验 baseline 口径，除非后续明确重新启用。

## 研究问题与指标

当前问题定义：

```text
We study socialized learning among class-disjoint agents under architectural
heterogeneity and limited communication.
```

核心目标：

```text
可塑性：提高 acc_new，使 agent 学会其他三个 agent 的 75 个类别。
稳定性：保持 acc_expert，控制自身 25 个 expert classes 的 forgetting。
通信效率：在相同 raw image budget 下优于 Random real-image packet。
异构兼容性：不同 sender/receiver architecture 不需要模型空间对齐。
```

统一指标：

```text
acc_global   ：100 类全局准确率
acc_new      ：75 个 non-expert classes 的准确率
acc_expert   ：25 个原 expert classes 的准确率
forgetting   ：acc_expert_before - acc_expert_after
```

报告每个 agent 的结果，并对 4 个 agent 求平均；正式主结果使用 3 个 seed 的 mean ± std。

## 通信预算与 DSDM 规则

### IPC 与 factor

DSDM 当前默认：

```text
factor = 2
1 张 raw synthetic image → 2×2 decode → 4 张 effective training images
```

通信量只统计 raw packet images，不统计 decode 后的 effective images。

```text
IPC=10:
  每个 sender = 25 × 10 = 250 raw images
  每个 receiver 接收三个 sender = 750 raw images

IPC=50:
  每个 sender = 25 × 50 = 1250 raw images
  每个 receiver 接收三个 sender = 3750 raw images
```

### Feature index

当前自蒸馏必须匹配 sender backbone 的最后一个 non-logits semantic representation：

```text
ConvNet-3  -> f_idx=2 / idx_from=2 / idx_to=-1
ConvNet-4  -> f_idx=3 / idx_from=3 / idx_to=-1
AlexNet    -> f_idx=7 / idx_from=7 / idx_to=-1
ResNet-10-CIFAR-w0.5  -> f_idx=5 / idx_from=5 / idx_to=-1
ResNet-18-CIFAR-w0.5  -> f_idx=5 / idx_from=5 / idx_to=-1
ResNet-18-CIFAR-w1.0  -> f_idx=5 / idx_from=5 / idx_to=-1（仅诊断）
```

修改 `f_idx` 后必须同步 `idx_from / idx_to`。不能把旧的 ConvNet-4 `idx=2`、ResNet `idx=2/4` 重新带回当前实验。

### 蒸馏评估计划

新实验保留 `niter=10000` 作为蒸馏上限，但默认只在以下 checkpoint 做完整 evaluator retraining：

```text
100, 500, 1000, 2000, 3000, 5000, 7500, 10000
```

配置字段：

```yaml
distillation:
  evaluate_iterations: [100, 500, 1000, 2000, 3000, 5000, 7500, 10000]
```

空列表表示回退到旧的固定 `evaluate_iter=100` 协议。one-ResNet 已完成/在跑的三 seed 配置保留空列表，以确保主结果使用同一 checkpoint 选择协议。不要在同一组 seed 汇总中混用两种评估计划。

## 论文叙事口径

推荐动机链条：

```text
Socialized learning
→ class-disjoint local expertise
→ architecture-heterogeneous agents
→ 参数、梯度和中间特征难以直接对齐
→ input-space packet 是不同视觉模型的共享接口
→ Random real images 在低预算下知识密度有限
→ sender-specific distilled packets 提升单位通信知识密度
→ receivers 在学习新类的同时保持原 expert knowledge
```

MASC 是社会化学习目标的重要来源，也是当前对比方法之一，但本文不是把联邦学习算法简单替换成图像通信。DeSA 是 synthetic/social learning 方向的近邻方法。Random 是相同图像数量下最直接、最重要的真实数据对比。

当前论文不得声称：

```text
验证了硬件异构、异步或动态带宽
解决了隐私泄露问题
所有 IPC 下均优于真实图
MASC/DeSA 在其原始设定中无效
统一 ConvNet encoder 是当前主方法
```

隐私只能表述为不直接传输原始私有训练集；除非补充正式隐私攻击或 DP 实验，不能声称提供隐私保证。

## 代码修改原则

1. 优先复用现有 pipeline，不大规模重构 DSDM。
2. 不改变全局标签、不改变 100 维分类头。
3. 不把 VGG、ResNetAP 或统一 ConvNet packet encoder 重新加入当前主设定。
4. 新增模型时必须显式验证 feature index、训练 recipe 和输出维度。
5. 修改 packet 格式后必须运行 `validate_packets.py`。
6. DSDM 通信量始终按 raw images 统计。
7. 已有三 seed 主结果的配置协议不得静默改变；新协议必须使用新 run name。
8. 当前机器只有一张 RTX 4090。启动重蒸馏前先检查现有 GPU 任务，避免并行抢占显存。
9. 不删除第三方源码或历史结果文件；“不再作为当前 baseline”只表示从当前叙事中移除。
10. packet 历史路径可能通过硬链接无损去重；所有 packet 写回与 hub 注册必须采用原子替换，禁止原地截断。
