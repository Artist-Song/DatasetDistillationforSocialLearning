# Documentation Archive

此目录只保存被替代的历史说明和工作记录，不能作为当前方法、协议或正式数字的来源。

| Directory | Content |
|---|---|
| `old_instructions/` | 被当前 `AGENTS.md` 取代的 agent 指示 |
| `historical_protocols/` | 被当前 `PROJECT_SPEC.md` 取代的阶段性协议和论文上下文 |
| `dated_worklogs/` | 旧过程记录；当前关键决策已提炼到 `EXPERIMENT_LOG.md` |

文件名中的日期表示归档快照日期。需要恢复历史语境时，应与当前 registry 和原始结果文件交叉核对。
