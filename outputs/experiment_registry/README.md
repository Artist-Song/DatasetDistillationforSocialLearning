# Experiment Registry

This folder stores consolidated experiment result tables generated by `python scripts/update_experiment_registry.py`.

- `social_results_all.csv`: per-agent social-learning rows from pipeline CSVs, legacy CSV, and the old Excel summary.
- `method_summary.csv`: mean metrics grouped by run/method/init/logits/ipc.
- `centralized_results_all.csv`: centralized full-data upper-bound CSV rows.
